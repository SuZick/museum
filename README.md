# Музей вычислительной техники

Учебный проект: сайт-музей, на каждый экспонат — отдельная страница с 3D-моделью и описанием.

## Как запустить

Нужен [Node.js](https://nodejs.org) (версия 20 или новее).

```bash
npm install      # один раз — скачать библиотеки
npm run dev      # режим разработки: сайт на http://localhost:5173, изменения видны сразу
npm run build    # собрать готовый сайт в папку docs
npm run preview  # открыть собранный сайт на http://localhost:4173
```

### Без интернета (например, на защите)

Дважды щёлкните файл **«Запустить музей.bat»** в этой папке. Он соберёт сайт и откроет его в браузере.
Интернет не нужен: шрифты, модели и 3D-движок лежат внутри проекта.
Чтобы выключить сайт, закройте чёрное окно.

Нужно только, чтобы на компьютере был установлен Node.js и один раз выполнена команда `npm install`.

## Как выложить сайт в интернет (GitHub Pages)

Сайт будет открываться по ссылке вида `https://ВАШ-ЛОГИН.github.io/museum/` — в том числе с телефона.
Программы ставить не нужно, всё делается в браузере.

1. Зарегистрируйтесь на [github.com](https://github.com) (если ещё нет аккаунта) и войдите.
2. Справа вверху нажмите **«+» → New repository**. Название — например, `museum`.
   Выберите **Public** и нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. **Первая загрузка — готовый сайт.** Откройте в Проводнике эту папку (`site`) и перетащите в окно браузера
   папку **`docs`**. Дождитесь, пока файлы загрузятся, и нажмите внизу **Commit changes**.
5. **Вторая загрузка — код проекта** (чтобы его можно было показать преподавателю).
   Снова нажмите **Add file → Upload files**, выделите в папке `site` всё, **кроме `node_modules` и `docs`**,
   перетащите в браузер и нажмите **Commit changes**.
   GitHub принимает не больше 100 файлов за раз, поэтому загрузок две.
6. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите
   **Source: Deploy from a branch**, **Branch: main**, папку **/docs** и нажмите **Save**.
7. Через 1–2 минуты сайт заработает. Ссылка появится вверху той же страницы Settings → Pages.

**Как обновить сайт после изменений:** выполните `npm run build` (или запустите «Запустить музей.bat»),
затем в репозитории нажмите **Add file → Upload files** и снова перетащите папку `docs`.

> Папку `docs` не нужно править руками — она целиком пересоздаётся командой `npm run build`.

## Где что лежит

| Файл / папка | Что там |
|---|---|
| `src/data/exhibits.js` | **Все данные музея**: эпохи, список экспонатов, характеристики, описания, источники |
| `public/models/` | 3D-модели экспонатов в формате `.glb` |
| `public/logo.svg` | Логотип (он же значок вкладки браузера) |
| `src/pages/HomePage.vue` | Главная: список экспонатов по эпохам |
| `src/pages/ExhibitPage.vue` | Страница экспоната: модель, паспорт, описание, интересный факт, источники |
| `src/components/ModelViewer.vue` | Окно 3D-модели (вращение и приближение) |
| `src/styles.css` | Всё оформление; цвета — в самом начале файла |
| `src/assets/fonts/` | Шрифты Playfair Display и PT Serif (свободная лицензия SIL OFL) |
| `docs/` | Собранный сайт для публикации (создаётся командой `npm run build`) |
| `notes/model-references.md` | Справочные фото и заметки, по которым делались 3D-модели |

## Как добавить экспонат

1. Положить модель в `public/models/`, например `agat.glb`.
2. В `src/data/exhibits.js` у нужного экспоната написать `model: 'agat.glb'`
   (или добавить новый объект в массив `exhibits` — какие поля у него бывают, написано в начале файла).

## Как устроены 3D-модели

Модели собраны программно из простых деталей (брусков, цилиндров, рамок) с помощью [three.js](https://threejs.org).
Код моделей — в папке `models-src/`:

| Файл | Что там |
|---|---|
| `lib.js` | Общие инструменты: материалы, надписи, клавиши, клавиатуры |
| `laptop.js`, `boards.js` | Шаблоны ноутбука и материнской платы |
| `<id>.js` | Каждая модель в своём файле (например, `iskra-1256.js`) |
| `index.js` | Список всех моделей |
| `builder.html`, `builder.js` | Сборщик: показывает модели и сохраняет их в `public/models/` |

Чтобы пересобрать модели после правок:

1. Запустить `npm run dev`.
2. Открыть http://localhost:5173/models-src/builder.html?model=iskra-1256 — одна модель, её можно покрутить мышью;
   или `?model=all` — миниатюры всех моделей с размерами файлов.
3. Добавить к адресу `&save=1` — файл(ы) в `public/models/` перезапишутся.

Модель, сделанную в Blender, тоже можно использовать: экспортировать её в `.glb` (File → Export → glTF 2.0)
и положить в `public/models/`.

## Технологии

- [Vue 3](https://vuejs.org) — фреймворк для страниц
- [Vue Router](https://router.vuejs.org) — переходы между страницами
- [`<model-viewer>`](https://modelviewer.dev) от Google — показ 3D-моделей
- [three.js](https://threejs.org) — построение 3D-моделей экспонатов
- [Vite](https://vite.dev) — запуск и сборка проекта
